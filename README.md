# OIBSIP_DataAnalytics_Task2

## 📌 Objective
Perform customer segmentation analysis for an e-commerce company by grouping customers into distinct segments based on behavior and purchase patterns to inform targeted marketing strategies.

---

## 🔢 Steps Performed
1. **Data Loading & Cleaning** — Loaded dataset, checked for nulls and duplicates
2. **Descriptive Statistics** — Calculated key metrics like average income and spending score
3. **Visualization** — Explored gender distribution, age distribution and income vs spending
4. **Customer Segmentation** — Applied K-Means clustering using Elbow Method (5 clusters)
5. **Cluster Visualization** — Scatter plots to illustrate customer segments
6. **Insights & Recommendations** — Analyzed each segment and provided marketing strategies

---

## 🛠️ Tools Used
| Tool | Purpose |
|------|---------|
| Python | Programming Language |

| NumPy | Numerical Computing |

| Seaborn | Advanced Visualization |
| Scikit-learn | K-Means Clustering |
| Jupyter Notebook | Development Environment |

---

## ✅ Outcome
Successfully segmented 200 customers into 5 distinct groups — High Income High Spenders, Low Income Low Spenders, High Income Low Spenders, Low Income High Spenders, and Average customers — enabling targeted marketing for each segment.
